
# 📦 AdvPL & TL++ Source Repository

> Uma coleção centralizada, organizada e escalável de códigos-fonte, bibliotecas e rotinas diversas desenvolvidas em **AdvPL** e **TL++** para o ecossistema **TOTVS Protheus** e outros projetos corporativos.

---

## 📖 Sobre o Repositório

Este repositório serve como um portfólio e uma biblioteca pessoal de códigos. O objetivo principal é compartilhar soluções úteis, funções customizadas, pontos de entrada e integrações criadas para otimizar e expandir as funcionalidades do ERP TOTVS Protheus. 

Aqui você encontrará desde pequenos *snippets* (que resolvem problemas comuns do dia a dia) até arquiteturas mais complexas em TL++, utilizando orientação a objetos e integrações via API REST.

---

## 🚀 Tecnologias e Frameworks

*   **AdvPL** (Advanced Protheus Language)
*   **TL++** (TOTVS Language Plus Plus)
*   **Protheus ERP** (Dicionário de dados, MVC, Web Services)
*   **SQL** (Queries embutidas nas rotinas)
